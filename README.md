# DnkCode AML Alert Prioritization

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Run the EDA app locally:

```bash
streamlit run app.py
```

Run model training and create `team_2ABB3C78.csv`:

```bash
python -m src.model
```

The model reads both transaction Parquet files. The supplied `test_transactions.parquet` currently fails to deserialize and must be replaced with a clean download before predictions can be generated. The training file contains 6,987,663 rows. Do not use the sample submission's placeholder scores as predictions.

## Deliverables

- `team_2ABB3C78.csv` generated by `src/model.py`
- Public deployment of `app.py`
- `notebooks/eda.ipynb` describing the data and modeling decisions
